# Autonomous-driving-research

**Project Period:** March 2026 – July 2026

A structured research and implementation project focused on
autonomous-driving systems, covering perception, state estimation,
planning, control, robotics, simulation, and vehicle modelling.

## Repository Timeline

The technical work represented in this repository belongs to the
March–July 2026 project period. The repository was consolidated
afterward to organize the existing work, experiments, documentation,
and results into a reproducible Git-based project structure.

Consequently, Git commit dates represent repository organization and
version-control activity and should not be interpreted as the
original dates of individual project activities.

Development and simulation of a modular autonomous-driving system
covering perception, tracking, localization, planning, control,
ROS 2, and MATLAB/Simulink validation.
